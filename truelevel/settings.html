Help

Add to Home Screen — iPhone / iPad
  1. Open this page in Safari (not Chrome or an in-app browser).
  2. Tap the Share button (square with an arrow). On newer iOS it may be under the … menu.
  3. Scroll down the list and tap Add to Home Screen, then Add.

Not in the list? Scroll to the bottom of the share sheet and tap Edit Actions (or More) and enable it. It is also missing in Private Browsing.

Install — Android (Chrome)
  1. Open this page in Chrome.
  2. Tap the ⋮ menu at the top right.
  3. Tap Install app (or Add to Home screen) and confirm.
Install — computer
  1. Chrome / Edge: click the install icon at the right end of the address bar.
  2. Safari (Mac): File → Add to Dock.
How calibration works
  1. Pick 3 fixed points on the platform and always measure the height at exactly those points.
  2. Calibration turns each knob by a known amount and records how the 3 heights change. That builds a 3×3 matrix (height change per turn).
  3. When you measure, the app uses that matrix to compute how far to turn each knob so all 3 points end at the same height.
  4. Recalibrate whenever the platform, its knobs or the measurement points change.
